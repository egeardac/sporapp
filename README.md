# SporApp

Koşu takip uygulamasının Flutter ile yapılmış arayüz demosu. Backend yoktur; tüm veriler örnektir.

- **Tarayıcıda dene:** https://egeardac.github.io/sporapp/
- **Android APK:** [Son sürümü indir](https://github.com/egeardac/sporapp/releases/latest/download/SporApp.apk)

Bu depo yalnızca yayınlanmış web sürümünü (`app/`) ve telefon çerçeveli giriş sayfasını (`index.html`) içerir.
